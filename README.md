# Автобуси Тернопіль — Підгородне

Static recovery of the public bus timetable. Includes directions, stops, route filters, countdown and calendar export.

Live passenger reports, driver updates and the Telegram bot are not hosted here. The page explains this limitation. No Python files, credentials or private repository history are published.

Hosted on GitHub Pages. Timetable data is copied from the existing project; this migration does not verify the timetable with the operator.
